# Divya Mishra Portfolio

React portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local preview URL in the terminal.

## Build

```bash
npm run build
```

The production site is generated in `dist/`.

## Deploy with Vercel

1. Create a GitHub repository and add this project to it. Do not upload `node_modules` or `dist`; they are generated locally.
2. Sign in to Vercel using GitHub and choose **Add New Project**.
3. Import the portfolio repository. Vercel detects Vite automatically.
4. Confirm the build command is `npm run build` and the output directory is `dist`.
5. Select **Deploy**. Vercel will provide a public `vercel.app` URL.

Add the resulting URL to your resume, LinkedIn profile, and GitHub profile after deployment.

## Portfolio content

Edit the text and sections in `App.jsx`; edit the design in `App.css` and `index.css`.
